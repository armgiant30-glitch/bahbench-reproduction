# 实验四：逐层特征选择

## 目的

论文认为声学类任务偏好低层或中层特征，语义类任务偏好高层特征。本实验用同一个论文版 Transformer 下游，只改变基础模型的特征层。

## 对比点

- 同一模型、同一任务、同一 split；
- 只改变 `--layer`；
- 比较每一层的 WA、UA、WF1；
- 找到 WF1 峰值层。

## 判定规则

以 12 层 HuBERT-base 为例：

- `--layer 0`：卷积前端特征；
- `--layer 1-6`：低层/中层；
- `--layer 7-12`：高层。

判定：

- 最佳层位于 1-6：支持声学类任务偏好低中层；
- 最佳层位于 7-12：支持语义类任务偏好高层；
- 最佳层与末层差距小于约 1 个百分点：层偏好不明显；
- 不同模型结论不一致：不能形成稳定层偏好结论。

## 当前状态

主实验默认使用 `--layer -1`，即基础模型最后隐状态。逐层实验尚未在本轮 Transformer 结果中完成。旧线性探针的层曲线不作为论文版 Transformer 的结论。
