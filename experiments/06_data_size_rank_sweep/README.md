# 实验六：样本量 × LoRA 秩

## 目的

检验数据量增加时，LoRA 的最佳秩是否会右移。

## 固定条件

- 模型：HuBERT-base
- 任务：TORGO
- 下游：论文版单层 Transformer
- epochs：50
- batch：32
- LoRA：Q/K/V

## 扫描

```text
每类样本数：50, 100, 200, 500
秩：2, 4, 8, 16
```

## 判定

- 数据少时最佳秩小、数据多时最佳秩变大：拐点右移。
- 最佳秩长期固定在 8 或 16：拐点主要受任务或模型影响。
- 小数据高秩退化、数据增加后恢复：过拟合是主要因素。
