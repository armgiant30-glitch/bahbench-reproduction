# 实验五：池化方式对照

## 目的

论文解读 §9.5 提到均值池化和最大池化差异通常较小，但没有给出当前复现数据上的对照。此实验固定模型、任务、split、层和训练参数，只改变分类读取池化方式。

## 对比点

- `--pool cls`：使用 CLS/首 token 表示。
- `--pool mean`：对有效 token 表示求均值。
- `--pool max`：对有效 token 表示取最大值。

## 推荐任务

先只跑 TORGO，避免全任务重复消耗。

## 判定

- 三种池化差异小于 1 个百分点：池化不是关键变量。
- mean/max 明显优于或劣于 cls：池化需要纳入结论。
- 同时检查 WA、UA、WF1。
